## 🎯 Objetivo

Este repositório tem como propósito ensinar o processo de contribuição em projetos Open Source no GitHub, por meio de um laboratório prático da DIO.

Você irá aprender:
- O que é um projeto Open Source;
- Como contribuir com projetos existentes no GitHub;
- Como criar seu próprio README de perfil;
- Como utilizar utilitários e badges no GitHub.

## 🚀 Como Contribuir (Passo a Passo)

1. Faça um **fork** deste repositório;
2. Clone seu fork localmente com `git clone`;
3. Crie uma nova branch: `git checkout -b minha-contribuicao`;
4. Adicione seu Profile README na pasta `community`;
5. Faça commit e push das mudanças;
6. Abra um **Pull Request** explicando sua contribuição.

Consulte o [CONTRIBUTING.md](https://github.com/digitalinnovationone/dio-lab-open-source/blob/main/CONTRIBUTING.md) para mais detalhes.

## 🧪 Desafio de Projeto da DIO

Agora que você já sabe como contribuir em um projeto Open Source, é hora de colocar em prática!

Para concluir este Desafio de Projeto, basta enviar a **URL do seu fork de um projeto Open Source que você contribuiu** para a entrega do desafio na plataforma [DIO](https://www.dio.me/).

> 📌 **Exemplo:**  
> A URL `https://github.com/falvojr/dio-lab-open-source` é o fork feito pelo usuário `falvojr`.

## 👤 Contribua com seu Profile README

Uma das formas de contribuir neste repositório é adicionando seu README de perfil no diretório `community`, com informações que deseja compartilhar com a comunidade. Você pode incluir:

- Badges indicando suas habilidades;
- Cards com estatísticas do GitHub;
- Links para seus projetos, artigos ou desafios da DIO;
- Chamadas para colaboração.

🎨 **Inspire-se** consultando os exemplos na pasta [`community`](https://github.com/digitalinnovationone/dio-lab-open-source/tree/main/community).  
🔧 Veja também utilitários disponíveis na pasta [`utils`](https://github.com/digitalinnovationone/dio-lab-open-source/tree/main/utils).

## 💬 Fórum do Repositório (GitHub Discussions)

O GitHub Discussions é um espaço para interação colaborativa. Em caso de dúvidas, abra uma discussão na aba **Discussions** do repositório.
